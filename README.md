## 🌟 About The Project

This project is a modern animated bakery website created to showcase bakery products with engaging visual effects and smooth user interactions.

The website includes multiple sections such as featured products, customer reviews, special desserts, and animated elements to create a lively user experience.

---


## ✨ Features

🎞️ Smooth Animations  
🍩 Modern Bakery UI  
🧁 Product Showcase  
💬 Testimonials Section  
🍰 Featured Products  
✨ Hover Effects & Transitions  
📄 Multi-page Layout  
🧼 Clean & Organized Code  

---

## 🛠️ Built With

- HTML5
- CSS3
